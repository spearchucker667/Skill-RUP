# Support

Welcome to Skill-RUP! We are happy to help you successfully use and integrate this skill.

## Where to get help

- **Bug Reports & Feature Requests:** Please use the [GitHub Issue Tracker](https://github.com/spearchucker667/Skill-RUP/issues). Ensure you use the appropriate issue form.
- **Documentation Issues:** For missing or incorrect documentation, please file a Documentation issue.
- **Security Reports:** Please review our [Security Policy](SECURITY.md) and report vulnerabilities privately. Do **not** use the public issue tracker.
- **Upstream RUP Protocol Issues:** If your concern relates to the canonical RUP Protocol semantics (the content of `protocol/rup-protocol.yaml` or schemas), please file an issue with the [upstream RUP Protocol repository](https://github.com/spearchucker667/RUP-Protocol).
- **Agent Platform Integrations:** If you have trouble integrating Skill-RUP into a specific agent framework, please review our compatibility matrices and file a standard bug report.
